## 4. 版本来源与不覆盖原则（实现事实）

- `documentVersion` 来源链路：入库 metadata `version`（`VectorMetadataBuilder.buildTrace` 已写）→ `RetrievalHitMapper` 读 `metadata.version` → `RetrievalHitView.version` → `RetrievedChunk.version` → `RetrievedChunk.toKnowledgeChunk` 写入 `KnowledgeChunk.documentVersion` → `CitationRegistry.toDto` 映射到 `CitationDto.documentVersion`。
- 版本按**每条检索命中的 Chunk 自身 metadata** 透传，不查询数据库"当前最新版本"，因此同一 sourceId 的 V1 检索结果不会被 V2 覆盖（由 `sameDocumentDifferentVersionsKeptPerChunk` 守住）。
- 版本缺失（历史存量未写 version 的向量）如实为 null，DTO 序列化时按 `@JsonInclude(NON_NULL)` 隐藏，不补造。
