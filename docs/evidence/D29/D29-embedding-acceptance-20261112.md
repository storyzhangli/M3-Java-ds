## 真实调用与模拟的区别

### 真实调用

- 本地模型生成 4 个教学 Chunk 向量。
- 真实 PDF 通过 D28/D29 现有页面和 Chunk 链路生成 17 个 384 维向量。
- 本地模型没有 API 费用和 Key。

### 受控模拟

- 重试成功、重试耗尽。
- 非法 API Key 对应的永久失败分类。
- 云端模型切换和索引隔离元数据。

- 精确 Tokenizer。
- VectorStore 持久化和 RAG。
