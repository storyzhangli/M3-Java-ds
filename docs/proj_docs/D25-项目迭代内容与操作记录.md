## 4. 设计交付

### 4.1 KnowledgeDocument

定义：

- 稳定 `documentId`
- 标题、类型、来源、文件标识
- 内部存储定位
- 不可变 `version`
- 状态、生效/失效时间
- tenant/plant/org 范围
- visibility 与 `permissionPolicyId`
- 语言、摘要、内容哈希、解析状态
- 设备系列/型号、适用范围
- 创建/审核/发布/归档时间

完整字段见：

- `D25-knowledge-document-schema.md`
- `D25-knowledge-document-schema.json`

关键选择：

- 权限标签不是最终授权，`permissionPolicyId` 指向权威 ACL。
- 发布后内容修改必须创建新版本。
- 只有 PUBLISHED 且有效期正确、权限通过的版本可检索。

### 4.2 Chunk

定义：

- `chunkId/documentId/documentVersion`
- `chunkGeneration/chunkIndex`
- 文本、哈希、语言
- 章节、页码、字符范围、来源定位
- parser/chunker/index 版本
- 生命周期状态
- 父权限策略和权限版本
- 设备/故障码/部件/维修类别标签
- 可测量 Token 数
- Embedding 规划的模型、维度、向量记录 ID 和状态

完整字段见：

- `D25-chunk-schema.md`
- `D25-chunk-schema.json`

关键选择：

- 重切分创建新 generation，不原地覆盖。
- Embedding 与 Chunk 分离版本。
- Chunk 不得扩大父文档权限。
- 权限变化无需重嵌入，实时权限版本参与过滤/缓存键。

### 4.3 RAG 模块边界

覆盖：

1. Knowledge Ingestion
2. Parsing
3. Chunking
4. Metadata
5. Embedding
6. Vector Store
7. Retrieval
8. Context Assembly
9. RAG Generation
10. Evaluation

当前：

- Citation Registry/Context Assembly 已有。
- Embedding/Vector Store/完整 ACL 未实现。
- Evaluation 本轮定义基线。

完整职责表与依赖图见 `D25-rag-module-boundary.md`。
