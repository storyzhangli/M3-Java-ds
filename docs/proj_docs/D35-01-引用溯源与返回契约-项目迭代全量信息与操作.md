## 一、迭代目标与范围

本轮承接 D34（基于证据回答与无证据拒答），补齐「引用溯源与返回契约」：

1. 回答返回 **sourceId / 标题 / 页码列表 / 段落索引 / 有限 excerpt** 等溯源字段；
2. 落实 **URL 协议黑名单**、**删除竞态与批量核验**、**SSE 与同步 API 同语义**、**前端安全渲染（移除 innerHTML）**、**入参 @Valid 校验**；
3. 产出 **≥14 条引用核验用例集 + 7 指标**。

关键设计原则：**新增字段 + 向后兼容**，不改既有 `id`（请求级 S 编号）语义；**稳定 sourceId（=真实 documentId）与请求级 citationId（S1/S2）分离**；页码缺失如实置 null 不补造；excerpt 只能来自真实 chunk 原文有限截取，禁止模型生成/改写。

## 三、引用溯源字段契约

```json
{
  "id": "S1",
  "sourceId": "doc-r2",
  "documentId": "doc-r2",
  "chunkId": "c-r2-01",
  "title": "R2 型水泵维护手册",
  "sourceType": null,
  "section": null,
  "page": 15,
  "pageNumbers": [15, 16, 17],
  "paragraphIndex": 3,
  "score": 0.62,
  "excerpt": "R2 型水泵常见故障：E50 表示排气阀堵塞……",
  "url": null
}
```

- `id`：请求级 citationId（S 编号），本轮有效；
- `sourceId`：稳定来源标识，跨请求不变，当前映射真实 documentId（系统无独立来源 ID，如实映射不新造）；
- `page`：向后兼容单值（pageNumbers 首个）；
- `pageNumbers`：跨页片段完整列表；无物理页为 null，不补造；
- `paragraphIndex`：真实切分来源（首个非空段落索引）；
- `score`：余弦相似度，仅内部溯源，前端不展示；
- `excerpt`：来自真实原文，≤200 UTF-16，代理对边界不切断。
