## 一、迭代目标与范围

本轮承接 D34（基于证据回答与无证据拒答），补齐「引用溯源与返回契约」：

1. 回答返回 **sourceId / 标题 / 页码列表 / 段落索引 / 有限 excerpt** 等溯源字段；
2. 落实 **URL 协议黑名单**、**删除竞态与批量核验**、**SSE 与同步 API 同语义**、**前端安全渲染（移除 innerHTML）**、**入参 @Valid 校验**；
3. 产出 **≥14 条引用核验用例集 + 7 指标**。

关键设计原则：**新增字段 + 向后兼容**，不改既有 `id`（请求级 S 编号）语义；**稳定 sourceId（=真实 documentId）与请求级 citationId（S1/S2）分离**；页码缺失如实置 null 不补造；excerpt 只能来自真实 chunk 原文有限截取，禁止模型生成/改写。

## 三、引用溯源字段契约

```json
{
  "id": "S1",
  "sourceId": "doc-r2",
  "documentId": "doc-r2",
  "documentVersion": "V2.0",
  "chunkId": "c-r2-01",
  "title": "R2 型水泵维护手册",
  "sourceType": null,
  "section": null,
  "page": 15,
  "pageNumbers": [15, 16, 17],
  "paragraphIndex": 3,
  "score": 0.62,
  "excerpt": "R2 型水泵常见故障：E50 表示排气阀堵塞……",
  "url": null
}
```

- `id`：请求级 citationId（S 编号），本轮有效；
- `sourceId`：稳定来源标识，跨请求不变，当前映射真实 documentId（系统无独立来源 ID，如实映射不新造）；
- `documentVersion`：文档版本（R03 新增），来自该条检索命中 Chunk 的真实入库 metadata，**不查询"当前最新版本"、不从最新版本反向覆盖历史检索结果**；缺失为 null 不补造；
- `page`：向后兼容单值（pageNumbers 首个）；
- `pageNumbers`：跨页片段完整列表；无物理页为 null，不补造；
- `paragraphIndex`：真实切分来源（首个非空段落索引）；
- `score`：余弦相似度，仅内部溯源，前端不展示；
- `excerpt`：来自真实原文，≤200 UTF-16，代理对边界不切断。

## 七、R03 整改记录（验收 8.4/10 后）

### 7.1 任务一（P0）：URL 安全校验修复

- **问题**：旧 `extractHost` 字符串拆分，`https://[::1]/admin` 的 host 为 `[::1]` 与 `::1` 不匹配、`https://127.0.0.1?x=1` 把查询串并入 host，两处边界被放行。
- **修复**：改用 `java.net.URI` 解析；scheme 白名单；userinfo 一律拒绝；IPv4 严格 4 段判定（前导零变体拒绝）；IPv6 剥离方括号后判定回环/未指定/链路本地/ULA/组播，IPv4-mapped 提取低 32 位判定。
- **测试**：`UrlSafetyPolicyTest` 从 16 个扩展到 **29 个**，覆盖任务书表格全部 13 类 + 公网 IPv6 允许 + 端口/前导零/协议相对等边界。

### 7.2 任务二（P1）：documentVersion 补齐

- 版本链路原有：metadata `version` → `RetrievalHitMapper` → `RetrievalHitView.version` → `RetrievedChunk.version`。
- 本轮补齐：`RetrievedChunk.toKnowledgeChunk` → `KnowledgeChunk.documentVersion` → `CitationDto.documentVersion`，同步与 SSE 共用同一 DTO。
- **按命中 Chunk 自身版本透传，不查当前最新版本**：同一 sourceId 的 V1 检索结果不会被 V2 覆盖（`CitationVersionContractTest` 同文档 V1/V2 用例守住）。
- 缺失如实为 null（语料 JSON 无版本字段的链路恒 null）。

### 7.3 任务三（P2）：引用语义支持边界说明

- 见 `D35-02` 第八节：明确区分 **Citation Existence Validation** 与 **Claim-level Grounding**，列出 `PostGenerationValidator` 检查范围与局限，给出 2 个"引用真实但结论不受证据支持"反例，完整 Claim-level Grounding 标记为后续迭代。
