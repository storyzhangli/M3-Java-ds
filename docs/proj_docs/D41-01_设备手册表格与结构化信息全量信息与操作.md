## 3. 数据模型（共享 ai_db 预建表适配，禁 ALTER）

- `d41_table_extract` / `d41_table_row` 由 **one 线预建**（0 行）。two 线裁决：不 ALTER、不 DROP（他线资产保护）。物理 18 列契约适配：
  - `version` 物理 **int**，代码契约 String（写数字串，D10）；
  - 无 `linked_chunk_ids_json` 列 → 关联持久化降级为 `detect_flags` 记 LINKAGE_MISSING，**linkedChunkIds 读面实时计算**（`recomputeLinkage`，S4 实证 linkedCount=1/missingCount=0）；
  - degradeStatus 映射 `status` 列 ACTIVE/DEGRADED；
  - `continuation_of_table_id` 复用为续表关联列；source_global_* 两列两线不用留 NULL。
- `cells_json` schema（冻结）：`[{"h":"列名","v":文本或null,"t":"number|string|null","u":"单位或null"}]`；`header_snapshot_json`=normalize 后表头数组；`record_hash` 行级 SHA-256；`source_line_number` 源文本行号。
- 行文本落 `knowledge_document_content`（byte[] 列）→ reExtract 读**原始字节全型重抽取**（不依赖丢失文本形态）。

## 10. 踩坑记录（本轮全部实证，按杀伤力排序）

1. **TWO_EMBEDDING_ENABLED=false 启动崩**（D11）：TwoPgVectorConfiguration 无条件装配 → requireValid 抛"Embedding 配置未启用"。
2. **source 列落库空串**：register 响应 echo 的 source≠落库值 → `source LIKE 'd41t-%'` 清理**永远打不中**（R4 S9 假成功、R5 才发现 8 表残留）→ 清理/核验必须用 docmap.json UUID 权威清单；兜底清理必须放 finally（正式段在 try 外 throw 路径不执行）。
3. **对账器 javac InterruptedException 未处理**：`reconcile` 声明 throws IOException 不够，改 throws Exception。
4. **pwsh hashtable `ForEach-Object { $($_.Key) }` 插值复现为空**（S3 显示 bug，repro 实证）→ 改显式 `foreach ($k in @($a.Keys))`。
5. **权限断言匹配不到 AUTH_FORBIDDEN**：GlobalExceptionHandler 把 RetrievalException 归一 4001+msg，reason 码不外泄 → 断言按 msg 文本。
6. **TABLE_ORPHAN SQL 1267 Illegal mix of collations**：one 线预建表 utf8mb4_0900_ai_ci vs knowledge_document general_ci → join 两侧显式 COLLATE。
7. **pwsh native 传参破坏 `\"`** → MySQL JSON 断言用 `JSON_ARRAY()` 函数构造。
8. **pdfbox 3.x 无 PDDocument.load** → `org.apache.pdfbox.Loader.loadPDF(File/byte[])`；getXObjectNames 不抛 IOException。
9. **NoResourceFoundException 被包成 code=5000**（非 404）→ OFF 断言语义改"未装配=code≠200 + 日志 NoResourceFoundException 实证"。
10. **宽排表头 24pt 切分碎成单 cell 被区域条件丢弃** → 整表上移错位（D13 pendingRow 半间隙吸收）；**连续中文标题不受影响**（12pt 重切仍 1 段）。
11. **`25x52x15` 误判 number/unit=x52x15**（D13 DIMENSION_SUFFIX 否决）。
12. **夹具文本右缘物理压列锚点**（Merged BC across e≈197 粘连 D2v@190）→ 受控构造需校验 x 覆盖区间，文本改 `Merged Cells`。
13. **OFF 验证脚本 `Join-Path $ev "D40\R03\scripts"` 双重拼接**（$ev 已含 D41）→ DbExec ClassNotFoundException → DB 断言全空失真；且首轮 finally 清理同样失败静默（错误被 Out-Null 吞）→ 残留文档占 content_hash 使第三轮 import 4092 连锁 4091。教训：**脚本路径一律绝对化；清理兜底失败必须显式报错**。
14. **txt 文档默认策略 vector-index 报 4091**（"无页面级文本，不能执行 PDF Chunk 预处理"）→ OFF 实证改用 PDF 夹具文档。
