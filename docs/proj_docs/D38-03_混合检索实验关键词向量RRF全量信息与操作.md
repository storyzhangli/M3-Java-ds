## 7. 踩坑记录（全部本轮真实踩中并修复）

1. **裸 @RequestMapping 类不被 MVC 识别**：`RequestMappingHandlerMapping#isHandler` 只认类级 `@Controller`/`@RestController`（元注解）。@Bean 工厂注册的 HybridRagController 端点实测 NoResourceFound(5000)。修复：类级 `@Controller + @ConditionalOnProperty` 条件化扫描 + 装配逻辑移入构造器，删 @Bean 工厂。教训：**"非组件注解防扫描"的推断未经真实启动验证即为假设**——单测手动 new 全绿≠Spring 装配可用，L2 必须真启动。
2. **@Service 多构造缺 @Autowired**：KeywordSearchService（public 3 参 + private 4 参测试工厂）enabled=true 启动即 "No default constructor found"。修复：装配入口构造加 `@Autowired`。单测因手动 new 不暴露，同属 L2 真实启动才能拦住。
3. **Maven repackage 文件锁**：实例 A 运行中 package → 无法 rename fat jar。程序：先停自管实例再打包；P3 回归必须在**最终 jar** 上执行（本轮实际执行了两轮回归并保留过程证据）。
4. **javac @argfile 反斜杠转义**：Windows 路径 `\t`（如 `...\D38\temp_docs`）在 argfile 双引号内被解析成 TAB。修复：argfile 内路径统一正斜杠。
5. **RRF 分数≠余弦量纲**（任务书 §3.2 预置，实测确认）：决策链 0.15 门禁必须消费向量路原始余弦（HybridRagRetrievalService 回填），评测器 MISS_RECALL_LOW_SCORE 标签判定也仅对 PURE_VECTOR 适用——对 HYBRID 记录用 RRF 分套 0.15 会系统性误标，方法学修正已文档化。
6. **summary 抄写 SHA 尾位失真**：执行期摘要 `…34bfc` 与磁盘 manifest/实测 `…34bec` 不一致，以磁盘为准并回改代码——纪律：哈希断言永远从冻结 manifest 现读现比，摘要不是证据源。
7. D37 评测器 probe 硬编码 8080：hybrideval 已改从 baseUrl 解析端口（回归跑用 8080 原生兼容）。
