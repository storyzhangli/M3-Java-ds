## 四、接口契约

### 4.1 请求（POST /api/v1/rag/answer）

```json
{
  "query": "数控机床主轴过热报警时应该怎么处理？",
  "topK": null,
  "documentId": null,
  "version": null,
  "strategy": null
}
```

- `topK`：null 沿用 `app.rag.top-k`（再空则沿用 `app.retrieval.default-top-k`=5）；
- `documentId/version/strategy`：可选检索过滤，值白名单 `[A-Za-z0-9._:-]{1,128}`（沿用 D32 检索校验）。

### 4.2 响应（HTTP 恒 200，`Result<RagResponse>`）

```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "query": "数控机床主轴过热报警时应该怎么处理？",
    "status": "SUCCESS",
    "statusMessage": "回答成功生成",
    "answer": "……（含 [S1] 等引用编号）",
    "sources": [ { "id": "S1", "documentId": "…", "chunkId": "…", "page": 12, "excerpt": "…" } ],
    "citedSourceIds": ["S1"],
    "citedSources": [ { … } ],
    "retrievalHitCount": 3,
    "retrievalElapsedMillis": 12,
    "scoreSemantic": "COSINE_SIMILARITY",
    "contextChunkCount": 2,
    "contextUsedChars": 318,
    "contextTruncatedChars": 0,
    "droppedUnknownMarkers": 0,
    "generationModel": "deepseek-flash",
    "mocked": false,
    "elapsedMillis": 2100
  }
}
```

**来源语义（诚实约束）**：`sources` = 进入上下文、提供给模型的证据来源，不宣称
"全部被模型引用"；模型实际引用以 `citedSourceIds` / `citedSources` 为准（由
`CitationRegistry.validateAndStrip` 清洗后统计）。

### 4.3 五态语义

| status | 含义 | 是否调用模型 | 触发条件 |
| --- | --- | --- | --- |
| `SUCCESS` | 回答成功生成 | 是 | 检索命中且组装可用且生成成功 |
| `NO_HIT` | 检索成功无命中 | **否** | 向量检索返回 0 条 |
| `NO_USABLE_CONTEXT` | 有结果无可用上下文 | **否** | 全低于 min-score 或预算装不下 |
| `RETRIEVAL_FAILED` | 检索执行异常 | **否** | pgvector 等基础设施异常 |
| `GENERATION_FAILED` | 生成执行失败 | 是（已调用） | 模型超时/异常 |

参数错误（空请求/空查询）不走五态：抛 `RetrievalException(PARAM_INVALID)`，
由既有 `GlobalExceptionHandler` 统一返回 `Result.fail`。
